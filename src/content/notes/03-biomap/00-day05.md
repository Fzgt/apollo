**八个核心点：**

| # | 要点 |
|---|---|
| 1 | **server state 和 client state 是两种东西**——它的真身在服务器上，你手里只有一份可能过期的副本 |
| 2 | 三层里**中间那层是枢纽**：queryOptions 独立成层，预取和读取才能共用同一份 key 和 fn |
| 3 | **queryKey 对不上，预取就白做**（还多打一倍请求）；代码用 `Omit<'queryKey'\|'queryFn'>` 在**类型层面**锁死 |
| 4 | **invalidate = 声明这份数据不可信了（声明式）**；refetch = 现在就去拿。mutation 后用前者 |
| 5 | **`staleTime` 管新鲜度，`gcTime` 管生命周期**——数据可以 stale 但还在缓存里 |
| 6 | ⭐ **「文档是约定，ESLint 是约束」**——这一天的统领句，同时解释了架构边界和 MSW |
| 7 | **MSW 拦在网络层**，所以 API 函数、拦截器、序列化全是真跑的。**和 [Periplus 的 seam](/docs?section=periplus&item=n14-server-tests) 同一原则** |
| 8 | 命令式 SDK 共处：**划一块框架不碰的飞地**，交界处只走**事件 + 显式调用** |

第 1–5 点见[TanStack Query 三层](/docs?section=biomap&item=d5-query)，第 6–7 点见[把约定变成约束](/docs?section=biomap&item=d5-constraints)，第 8 点见[命令式 SDK](/docs?section=biomap&item=d5-interop)。
