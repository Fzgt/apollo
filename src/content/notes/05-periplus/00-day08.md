**要产出的三件事：**

1. **30 秒口播稿**（草稿在必看篇），改成自己的话**出声练**
2. **能默写六阶段的三套名字**（简历全称 / 代码枚举 / 代号）
3. **把「agentic workflow 不是 multi-agent」那三条依据背下来**

**六个核心点：**

| # | 要点 |
|---|---|
| 1 | 六个阶段之间只通过**带类型的契约**交接，编排器**不知道每个阶段内部在干什么** |
| 2 | ⭐ **控制流写死在 `STAGE_ORDER` 这个 tuple 里**，而且只允许跑**连续前缀**——可以在 plan 之后停，但不能没跑 research 就跑 write |
| 3 | ⭐ **零个 tool call**——`grep` 返回空。模型只在固定位置产出结构化输出，**没有调用外部能力的口子** |
| 4 | ⭐ 连检索计划都是普通函数算的（`research.py:107`，docstring 写着 *without spending a model call*） |
| 5 | **契约一直延伸到前端**：Pydantic → OpenAPI → `openapi-typescript` 生成 TS。**后端改字段是编译期报错，不是线上白屏** |
| 6 | 不用一个大 prompt 的理由：**没有中间检查点就无法归因**；拆开后每阶段有类型化产物 + 一道 gate，**而且能用不同模型和不同 thinking 级别** |

第 2–4 点合起来就是 Q5 的答案，**这是这一天最该背熟的一段**。
