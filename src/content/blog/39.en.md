## Tree problems: when do you need a helper function?

- Ask whether the function's input and output already match the answer you want. `maxDepth` does, so it needs no helper; an inorder traversal does not.
- Or ask whether the parameters line up. Checking mirror symmetry needs two nodes to compare, and `isSymmetric` only takes one.

```js
function isSymmetric(root: TreeNode | null): boolean {
    return isMirror(root.left, root.right);
};
```
