## ④ 邮件服务与首个 CI

> NestJS and Fastify service for subscription emails and scheduled payment reminders — Dockerized, cron-triggered, deployed to EC2 under PM2 through GitHub Actions — and of the repo's first CI gate: lint, typecheck and build on every push.

**复习重点**：NestJS module/controller/provider 与 DI · 为什么 Fastify 不是 Express · cron 任务的重复发送与幂等 · 任务中途失败 · image vs container、layer cache · PM2 的 restart/logs · **Docker 和 PM2 是否重复** · CI 与 CD 的区别

**注意**：GitHub Actions 在这里同时承担了 CI gate 和部署，这两件事要分开讲清楚。`deploy.yml` 是 **CD**，`ci.yml` 才是 CI。

### 必读代码

| 文件 | 看什么 |
|---|---|
| `beyz-server/src/main.ts:3,6` | `FastifyAdapter` / `NestFastifyApplication` |
| `beyz-server/src/modules/tasks/jobs/email.job.ts:19` | `@Cron(CronExpression.EVERY_MINUTE)`；`:17-18` 还留着按天/按十分钟的注释版本，**为什么最后是每分钟要能答** |
| `beyz-server/src/app.controller.ts:18-27` | 手动触发 cron 的口子 |
| `beyz-server/Dockerfile:3,17` | `npm install -g pm2 pnpm`、`CMD ["pm2-runtime", "start", "dist/src/main.js"]` |
| `beyz-server/.github/workflows/deploy.yml` | push to main → 配 AWS 凭证 → SSH 进 EC2 → `git pull` + `docker-compose up -d --build`。**这是 CD** |
| `beyz-web/.github/workflows/ci.yml` | `push: branches:["**"]`，两个 job：lint + typecheck、build。**这个文件的创建提交是你的**（2024-04-08 #163） |
