## 🔴 今天必看

⚠️ **这一天 Day 1 已经写透了**：[#16 · golden set 四个数字](/docs?section=periplus&item=n16-golden-set)。**今天只补三块 + 口播稿。**

**五个核心点：**

| # | 要点 |
|---|---|
| 1 | ⭐ **冻结输入、断言性质**——断的是「产出几条声明、引用有没有断链、判决分布、token 成本」，**不是「模型该输出哪句话」** |
| 2 | ⭐ **oracle 读的是 case 标签不是证据**，模型判断成了常量，**指标一动一定是代码动了**——这是把真实回归和模型漂移分开的唯一办法 |
| 3 | ⭐ **过拟合的三道结构性防线**，最强的一条是：**改 Auditor 的 prompt 根本不会让指标移动**，想调绿结构上就做不到 |
| 4 | `compare()` 会**把只在一份报告里出现的 case 列出来**——防止「删掉一个不过的 case」伪装成进步 |
| 5 | `prompt_hash` **不能跨 run 做归因**（混进了每次新生成的 UUID，两次一样的运行哈希不同），所以改摘 stage system prompt |

> **第 2、3 点合起来是这条 bullet 的核心论点。第 4 点和 [`gap_rate` 返回 1.0](/docs?section=periplus&item=n16-golden-set) 一起讲——「写评测的人想过自己的评测会怎么被骗」。**
