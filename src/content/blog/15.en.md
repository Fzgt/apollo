Both the code analysis and the report can run on SonarCloud. All you need is for CI to push the data up — either the Sonar Scanner or the GitHub Actions plugin.

### What the report covers

- Possible runtime errors, unused variables, dead code
- Security holes: XSS and SQL injection risk, unsafe functions or library versions
- Code smells: functions and classes that grew too long, duplicated code, bad naming, deep nesting
