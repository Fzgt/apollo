# exams · 模考卷

自测用的闭卷题。一份卷子从出题到进站里，走这四步：

1. **出卷** —— 我写一份 `YYYY-MM-DD-<范围>-<序号>.md`，只有题目和空的答案槽，没有答案。
2. **作答** —— 你在 VSCode 里打开，把答案写进 `<!-- ANSWER:xx -->` 和 `<!-- /ANSWER -->` 之间。**两行标记不要删**，我靠它们定位。写不出来就留空或者写「不会」，留空比编一段更有用。
3. **批改** —— 你说一声「改吧」，我生成同名的 `-graded.md`：你的原答案一字不动地留着，每题下面加我的批改（漏了什么、说错什么、哪句话不能这么出口）和参考答案。
4. **入站** —— 批改稿进 `/mock` 页（导航栏「模考」），和题库并列，以后能翻回来看自己上次错在哪。

## 约定

- 卷子是**闭卷**：作答时不要开 `/questions`。开了就成了抄写练习，不是模考。
- 参考答案对应的是 `src/content/questions/beyz.ts` 里的题号，批改时我会标出来，方便你回去对。
- Part D 那种一行题，答不上来直接空着——那正是它存在的意义，专抓「意思懂了但名字说不出口」。
