## cc-switch

> Add the CC Switch Homebrew tap:
> `brew tap farion1231/ccswitch`
> Then install it:
> `brew install --cask cc-switch`

### If you are tired of confirming permissions, start with this flag to skip the unnecessary prompts:

```
claude --dangerously-skip-permissions
```

## Installing common Claude Code skills

### Method 1

Download the archive from https://skillsmp.com/zh, unzip it, and drop the folder into the right system directory.

### Method 2

Start Claude and run:

```
/plugin install skill-creator@claude-plugins-official
# the claude-plugins-official marketplace is registered by default, so no `marketplace add` is needed;
# anthropics/skills is a different marketplace and has no standalone skill-creator plugin
```

Then ask it: "use skill-creator to create a skill called deploy-check that runs a pre-deployment checklist".

(skill-creator is Anthropic's official skill development kit; it helps you build your own custom skills quickly.)

### Installing web-access (web browsing and search)

The web-access skill lets Claude Code reach the internet: search for current information, browse pages, extract data.

```
/plugin marketplace add browserbase/skills
/plugin install browse@browserbase
```

### Installing playwright-cli (browser automation)

The playwright-cli skill lets Claude Code drive a real browser and automate things: fill in forms, click buttons, take screenshots.

```
npm install -g @playwright/cli@latest
playwright-cli install-browser chromium
playwright-cli install --skills
```

### Installing superpowers (a full development workflow)

superpowers is the most popular Claude Code plugin at the moment. It supplies a complete software development workflow — requirements, design, implementation, testing — and guides the model through best practice at each stage.

```
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
```

### Install the LSP for whatever languages you use

It helps Claude Code understand the repository.

```
/plugin install typescript-lsp@claude-plugins-official
/plugin install pyright-lsp@claude-plugins-official
/plugin install gopls-lsp@claude-plugins-official
```

## Image and video generation skills

Put the downloaded zip in:

- macOS: `~/.claude/skills/`
- Windows: `C:\Users\<your username>\.claude\skills\`

The `secret-key` inside the skill has expired — remember to have Claude Code replace it with your own.

## Prompts for long-running tasks

Put them under the project. If your project is `C:\Users\<your username>\proj`, then they go in `C:\Users\<your username>\proj\prompts` (remember to unzip).

The example prompt translates OpenClaw's TypeScript into Python. Adjust it to whatever your project needs.

(The prompts folder is under Desktop/AI.)
